# 拾光专注 1.0.0

中文、免费、离线的每日任务与专注计时桌面软件。日常运行不需要账号、Node.js、开发助手或模型接口。

## 下载与启动

- **安装版**：下载 `Shiguang-Focus-1.0.0-Windows-x64.exe`，双击安装，可创建桌面快捷方式。
- **免安装版**：下载 `Shiguang-Focus-1.0.0-Windows-x64.zip`，完整解压后双击里面的 `拾光专注.exe`。可运行同目录快捷方式脚本，或右键程序发送到桌面。
- `Source.zip` 是开发源码，普通使用不需要下载。

目标为Windows11 x64。所有运行资源均在包内，首次下载后可以断网使用。数据自动保存在当前用户的 `%APPDATA%\ShiguangFocus\data`。

支持自定义时长、纯数字全屏、暂停、持续超时、手动完成、每日重复模板、拖动排序、优先级、备注与子任务、按日期的历史和统计，以及完整备份导入导出。

全屏按 **Esc** 返回清单，计时继续；按 **空格** 暂停／继续。时间到零不会自动完成任务。请定期在“设置与备份”中导出数据。

## 验证和限制

发布流程在Windows构建，执行Node逻辑测试和Electron桌面自动化，通过后才上传应用包。此前的Linux环境已通过23项核心测试和9项Electron桌面测试。Windows物理电脑上的安装、快捷方式、多显示器、真实休眠和音频仍需要实机确认。

本版本未进行商业代码签名，系统可能显示未知发布者。请核对下载来源，校验值见 `SHA256SUMS.txt`。完整使用说明、验收清单及构建方法在源码的 `docs` 目录。
