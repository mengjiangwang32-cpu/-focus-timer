# 拾光专注 1.1.0

免费、中文、离线的任务与专注计时桌面软件。本次升级加入更灵活的重复安排。

## 新增功能

- **指定星期**：周一至周日可多选，例如周一、周三、周五运动。
- **每隔N天一次**：从开始日期计算，例如25日开始，每3天一次为25日、28日、31日、次月3日。
- **自选开始日期**、表单近期日期提示和未来7天安排预览。
- 保留原来的每日重复，修改规则不改写已有任务、历史及用时。

任务在符合规则的当天打开软件时加入清单，同日不会重复生成，不补造错过日期。开始计时的具体时间仍由你决定。

## 下载与覆盖安装

普通用户优先下载 `Shiguang-Focus-1.1.0-Windows-x64.exe`：

1. 建议先在旧软件中导出一份备份。
2. 正常退出旧版，无需先卸载。
3. 双击新版安装器，保留原安装目录，完成后从桌面快捷方式启动。

安装标识与用户数据目录不变，保留1.0的任务、历史、模板、用时和设置。原每日任务继续每天执行；首次升级先自动保存一份 `before-v2-*.json` 原数据副本。新版可以导入旧版备份，新格式不供1.0读取。

也提供完整免安装 ZIP，需整体解压后运行 `拾光专注.exe`。`Source.zip` 供开发者使用，普通使用无需下载源码、Node.js或开发助手。数据保持在当前Windows用户的 `%APPDATA%\ShiguangFocus\data`。
