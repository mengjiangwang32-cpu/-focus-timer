# 拾光专注使用说明

## 安装与启动

在[正式发布页面](https://github.com/mengjiangwang32-cpu/-focus-timer/releases/tag/shiguang-v1.1.0)下载 `Shiguang-Focus-1.1.0-Windows-x64.exe` 安装包，双击按提示安装并创建快捷方式。也提供 `Shiguang-Focus-1.1.0-Windows-x64.zip` 免安装包。这是 Windows 11 x64 应用，不支持 Windows ARM 原生包或 32 位系统。文件需要由你下载到本机，发布到 GitHub 不会自动安装到你的电脑。

如果使用 `Shiguang-Focus-1.1.0-Windows-x64.zip`，请**先完整解压**到一个固定文件夹，再双击 `拾光专注.exe`。不能只复制 exe，也不要在压缩包内直接启动。

免安装版的桌面快捷方式可任选一种方法创建：

1. 双击同目录的 `创建桌面快捷方式.vbs`。
2. 右键 `拾光专注.exe` → “显示更多选项” → “发送到” → “桌面快捷方式”。如果系统禁用了脚本，使用此方法。

使用成品软件无需安装 Node.js，无需开发助手、账号或模型服务。这个版本没有商业数字签名，Windows 可能提示“未知发布者”。请核对交付来源和 `SHA256SUMS.txt`，不需要关闭系统安全功能。

## 添加和安排任务

点击“新建任务”，填写名称和预计分钟数（1～10080 分钟），选择高、中、低优先级。可以填写多行备注，添加一层子任务；子任务可上下移动调整顺序。预计时间是整个任务的预算。**第一次开始计时后预算固定**，其他详情仍可编辑。

点击任务名称或右侧箭头展开备注和子任务。子任务只记录勾选状态，不独立计时、不重复计入统计。全部子任务完成不会自动结束父任务。父任务仍有未完成子项时，软件会先询问是否仍要完成。

拖动每行左侧六点图标调整顺序；也可以聚焦该图标，按 `Alt + ↑/↓`。排序自动保存，优先级不会重排任务。未完成和已完成分组显示。

日期栏可切换前后一天或选择日期。新建任务属于当前选中的日期。归档前会确认，归档后从日常清单隐藏，但保留记录与统计，可用日期栏右侧的归档图标查看并恢复。

## 开始专注

任务旁点“开始”进入全屏。首次会说明两个快捷键：

| 操作 | 结果 |
| --- | --- |
| `Esc` | 返回清单，计时继续 |
| 全屏中的 `空格` | 暂停／继续 |
| 主界面“返回全屏” | 回到同一个计时器 |
| “结束本次” | 保存用时，任务保持未完成 |
| “完成任务”或任务勾选框 | 保存用时并标为完成 |

全屏覆盖应用所在显示器，只显示数字；允许系统快捷键和切换应用。小于一小时为 `MM:SS`，一小时起为 `HH:MM:SS`。到零只提醒一次，随后出现 `+` 号并继续显示超时，**不自动完成、不自动休息、不启动下一任务**。暂停时数字会变暗。

想临时查资料，按 `Esc`；计时继续，查完点击“返回全屏”。想把查资料时间排除，先暂停。输入文字时空格正常输入。

同一时刻只能有一个计时任务。切换时先确认，再保存原任务本次用时；分多次进行共用整项任务预算。例如预算20分钟，第一次10分钟，第二次12分钟，总用时22分钟，超时2分钟。取消完成勾选保留原有记录，可以继续。

## 重复计划：按星期或每隔几天

在“重复计划”点击“新建重复计划”，或新建任务时勾选“设为重复任务”。填写名称、时长和备注后，选择重复频率：

- **每天**：每日一项独立任务，兼容原版的每日重复。
- **每周指定星期**：点击周一到周日，可同时选择多个。例如周一、周三、周五运动，周二、周四读书。
- **每隔几天**：输入1～3650的整数，例如“每3天出现一次”。从开始日期计算：25日开始，每3天一次即25日、28日、31日、次月3日。

可指定“开始日期”，开始日前不会出现任务。表单会显示近期具体日期；页面上方显示未来7天的安排预览。每项任务仍由你自己决定开始计时的时间，不自动启动计时器。

保存重复计划时，只有今天符合规则才加入今天的任务清单；未来的任务在对应日期首次打开软件或跨日刷新时加入。当天多次打开不会重复生成，不补造没打开软件的日期。昨日未完成的任务仍留在昨日的历史中。

点击“编辑计划”可修改星期、间隔、开始日期、名称和预算。修改影响之后新生成的任务，不改写已经存在的任务或历史。同一天已经生成的实例不会重复生成。停用只停止后续安排；旧记录继续保留。

## 从1.0直接覆盖安装1.1

1. 建议先在旧版“设置与备份”中导出一份备份。
2. 正常退出旧版，再下载并运行新版安装包，不用先卸载。
3. 保留原来的安装目录，按提示完成安装，再从桌面快捷方式启动。

应用名称、安装标识和用户数据目录保持一致。原任务、历史、用时、每日模板及设置继续保留；原每日模板仍按每天执行。升级首次读取旧数据前，自动把原文件备份为数据目录中的 `before-v2-*.json`，确认副本保存成功后才升级。备份写入失败会停止升级并保留原数据。

新版可以导入1.0备份。新格式包含星期和间隔规则，1.0无法读取；如需回退，先额外保留新版本数据，再恢复升级前备份，不要直接让旧版打开新数据。

## 历史和统计

“历史与统计”按所选日期汇总父任务数量、完成数、预计、实际、超时；还可逐项查看备注、子任务状态及计时片段。

实际用时是所有运行片段累计，扣除暂停、软件关闭和休眠时间。超时为每项任务 `max(实际－预计, 0)` 后相加。未完成的超时任务仍统计超时，不算完成。完成且实际不超过预计为“按时完成”，否则为“超时完成”。

跨午夜计时保留原任务日期，新一天可以生成新的重复实例，但不会创建第二个并行计时器。归档任务继续计入所属日统计。

## 保存、退出和备份

更改自动保存。计时正常情况下每不到2秒保存检查点；正常关闭会保存并暂停。异常退出后恢复到最近检查点并暂停，通常最多损失最近约2秒，严重主进程卡顿或磁盘写入失败可能延长。休眠后保持暂停，唤醒请手动继续。

数据位于 `%APPDATA%\ShiguangFocus\data`，可在“设置与备份”中打开目录。更新程序或移动免安装目录不会主动清除用户数据；卸载默认也保留数据。同一 Windows 用户共享同一份数据，并不是随 U 盘移动的数据文件。

定期进入“设置与备份” → “导出备份”，将 JSON 保存到其他磁盘。备份包含任务、历史、模板、设置与计时数据。选择“导入备份”时会先验证整个文件，再询问是否完整替换当前数据，同时保存一份 `before-import-时间戳.json`。恢复的计时均暂停。错误文件不会替换数据。导入文件上限20 MB。

主数据损坏时会尝试恢复上一份有效自动副本并提示，损坏原件会另存保留；两份都无法校验时停止启动保护数据。请从手动备份恢复，不要删除数据目录来“修复”。未来版本若需要升级数据结构，必须在迁移前保留原格式备份；当前结构为第2版，升级前自动备份第1版原文件。

## 本版限制

- 已在 Linux 和 GitHub 托管的 Windows 环境运行自动化；Windows 11 物理电脑的安装、快捷方式、音频、系统休眠与多显示器仍须实机验收，见测试报告。
- 到时提醒使用系统短提示音，音量与可听性依赖系统设置，可在软件中关闭。
- 不同时遮盖多个显示器；不锁屏，不阻止其他应用和系统快捷键。
- 没有云同步，设备故障时需依靠自己导出的备份恢复。
